KEYBOARD

Shortcuts

Anywhere

/Jump to search
?Open or close this list
F1Search the help — how a feature works, not which key presses it
EscClose dialogs and menus, clear search or selection

Vehicles board

↑↓Move the cursor row
HomeEndJump to the first / last row
EnterOpen the cursor row's vehicle
SpaceSelect or deselect the cursor row
Shift+clickSelect a range of rows
Ctrl+clickToggle one row in or out of the selection
a…z 0…9Start typing to search — no click needed

Customers

↑↓Move the cursor row
HomeEndJump to the first / last row
EnterExpand or collapse the cursor row
EscCollapse the open row, then clear search and filters
a…z 0…9Start typing to search — no click needed

Tasks

↑↓Move the cursor row through the open list
HomeEndJump to the first / last row
EnterMark the cursor row done (or not done again)
SpaceSelect or deselect the cursor row for bulk edit
Shift+clickSelect a range of rows
EscDrop the selection, then the cursor
a…z 0…9Start typing to search — no click needed

Parts & Labor grid

TabPast the last money field on the last line: adds the next line
EnterOn the last line: next field — description, qty, cost, then a new line

Every field on the grid autosaves shortly after you stop typing — there is no save button to reach for.
